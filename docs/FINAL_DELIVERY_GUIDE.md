# Powertrade Crawler 最终交付使用与验收指南

> 多数据源 Agent 已增加完全离线的本地混合知识库。使用、维护、模型准备和故障处理见
> [RAG_GUIDE.md](RAG_GUIDE.md)，第三方许可见
> [THIRD_PARTY_NOTICES_RAG.md](THIRD_PARTY_NOTICES_RAG.md)。
> 正式 Windows 发布必须通过 [Windows 签名与干净机发布门禁](WINDOWS_RELEASE_GATE.md)。

适用版本：第十三周交付级打磨版
验收日期：2026-08-10

本文只说明当前已经交付的能力，不增加数据源、页面或 Agent 权限。软件的核心数据目录为
`data/powertrade.db`，凭据目录为 `.auth/`；两者都不应提交到 Git 或随公开源码分发。

## 一、新用户首次使用

### 使用打包版

1. 解压整个 `PowertradeCrawler` 文件夹，不要只复制 exe，也不要直接在压缩包内运行。
2. 把文件夹放到当前用户可写的位置，双击 `PowertradeCrawler.exe`。
3. 首次启动会自动创建 `.env`、`configs/`、`data/`，并在数据库不存在时复制轻量演示库；
   不会自动复制开发者凭据，也不会覆盖已有的 `data/powertrade.db`。
   分发包同时内置 `configs/gridstatus/datasets.initial.json` 轻量目录快照；没有 API Key
   或网络时也能先浏览目录。演示库包含五个来源的少量真实样例，方便首次启动立即试用
   浏览、筛选、看板、导出和 Agent 只读分析；用户后续采集会按自然键更新或追加。
4. 先打开左侧“数据总览”，确认各来源是否已有本地数据。
5. 打开“API 配置”，只配置自己需要在线采集的来源；保存后页面只显示状态，不回显密钥。
6. 先用一个地区、一天或一个小数据集做采集验证，再扩大范围。
7. 需要自动更新时进入“定时任务 / 数据维护”，创建任务后确认 Windows 触发器确实已安装。
8. 需要智能问答时确认本机免费 LLM 网关可用，再进入“多数据源 Agent”或 Elecheck 内的 Agent。

### 使用源码版

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m powertrade_crawler.cli init-db
.\.venv\Scripts\python.exe -m powertrade_crawler.cli gui
```

建议首次使用顺序为：数据总览 → API 配置 → 小范围采集 → 数据浏览/导出 → Agent → 定时任务。

## 二、API Key 与账号配置清单

| 功能 | 是否必须 | 新用户需要准备什么 |
|---|---|---|
| 浏览、筛选、导出本地数据 | 不需要 | 无 |
| GridStatus 在线采集 | 使用该来源时必须 | GridStatus API Key，部分数据集还受账号套餐限制 |
| ENTSO-E 在线采集 | 使用该来源时必须 | Transparency Platform 账号、RESTful API access、Security Token |
| Elecheck 在线采集 | 使用该来源时必须 | 有效 Authorization；目前没有公开自助开发者 Key 页面 |
| Elexon 在线采集 | 不需要 | Insights API 当前公开访问 |
| 广州电力交易中心采集 | 不需要 | 读取公开信息页面 |
| 两套 Agent | 使用 Agent 时必须 | 本机 `llm-router` 和至少一个可用的免费上游渠道 |
| 单个 LLM 平台 | 可选 | Gemini、ModelScope、NVIDIA、Groq 等任选至少一个，不要求全部注册 |

电力来源凭据保存在 `.auth/credentials.json`；LLM 上游 Key 只保存在项目外的本机网关中。
完整申请入口和逐步说明见 [API Key 与账号配置指南](API_KEY_SETUP_GUIDE.md)。不要把 Key、Token
或 Authorization 发给 Agent，也不要放入截图、日志、任务参数、数据库或 Git。

## 三、五个数据源的范围与限制

| 来源 | 已交付范围 | 主要限制 |
|---|---|---|
| Elecheck | 国内现货价格、代理购电、增量机制电价及专题看板 | Authorization 非公开自助申请；401 后需要重新获取；现货时间粒度依地区返回 |
| ENTSO-E | 26 个配置化欧洲市场、负荷、发电、输电、平衡和停运入口 | 数据集与区域组合不一定有数据；输入日期按 UTC；当地交易日需自行换算 |
| Elexon | 17 个英国需求、发电、价格、平衡、裕度、互联线和非 BM 服务入口 | 大型 BMU 查询应按日期和结算周期分批；快照或 STOR 返回 0 条可能是正常情况 |
| GridStatus | 数据集目录和已配置的北美 ISO/RTO 数据下载、浏览与更新 | 可用范围受 API 套餐、限流和数据集自身时间参数约束 |
| 广州电力交易中心 | 公开信息列表、正文与结构化内容块 | 依赖公开网站结构和可访问性；图片只保存 URL，不下载和 OCR |

程序会区分“无新数据”和“采集失败”。重复采集使用业务自然键 upsert；相同业务记录会更新，
不会因为每天重复运行而持续制造重复行。

## 四、Agent 能做与不能做的事情

Agent 可以：

- 查询本地数据目录、概况、时间序列、统计和受控跨来源比较。
- 回答软件操作、API 配置、导出和定时任务排障问题。
- 在参数完整时提出采集或受控定时任务操作，并等待用户审批。
- 在预设目录导出受控 CSV/PNG，记录会话、阶段事件和工具结果。
- 在失败时说明“为什么没有完成、是否修改数据、下一步怎么做”。

Agent 不可以：

- 绕过用户审批执行会改变业务数据的操作。
- 执行任意 SQL 写入、Shell、业务数据删除、任意文件浏览或凭据修改。
- 读取或回显 API Key、Authorization、本机免费网关 Key。
- 在免费渠道全部不可用时自动切换到付费模型。
- 编造本地不存在的数据、自动补零，或把不同口径的数据冒充为可直接比较。

用户拒绝审批、参数缺失、凭据缺失、本地无数据、网络失败、模型不可用或请求超出权限时，
Agent 都应给出完整失败说明；会话切换不会继承上一会话的待审批状态和业务参数。

## 五、定时任务配置与排障

“启用本地任务”只表示任务定义允许运行；只有“Windows 触发器 = 已安装”时，软件关闭后才会
由 Windows 按时启动。推荐不同来源错开 5 至 10 分钟，并先用“立即运行”完成一次验收。

来源级快捷任务支持 Elecheck、ENTSO-E、Elexon、GridStatus 和广州电力交易中心。一次来源更新
包含多个子步骤时，某个子步骤失败不会阻断其余步骤，最终状态会明确显示成功、无新数据、部分
成功、失败或跳过。相同任务并发触发时，第二次运行会被跳过并记录 `already_running`。

如果 Windows 任务被外部删除，刷新页面后系统会查询真实任务计划状态、清除失效关联，并提示
重新安装，不会继续把数据库中的旧名称显示为“已安装”。运行详情保存在 `scheduled_job_runs`。

常用命令：

```powershell
powertrade schedule-list
powertrade schedule-run 1 --force
powertrade schedule-install-windows 1
powertrade schedule-uninstall-windows 1
```

打包版由 Windows 使用以下形式在后台运行：

```powershell
PowertradeCrawler.exe --headless schedule-run 1
```

## 六、常见错误处理表

| 状态或错误 | 含义 | 建议操作 |
|---|---|---|
| 无新数据 | 请求成功，但当前范围没有新增/可返回记录 | 调整日期、区域或数据集；不要当作网络失败重复轰击接口 |
| 连接失败 / 断网 | 无法连接目标站点或本机网关 | 检查网络、代理、站点状态和网关进程后重试 |
| 请求超时 | 目标响应过慢，自动重试后仍失败 | 缩小日期范围；稍后重试；检查网络质量 |
| HTTP 401 | 凭据缺失、过期或无效 | 在“API 配置”重新保存有效凭据 |
| HTTP 403 | 账号无权限、套餐不包含或访问被拒绝 | 检查账号权限、套餐和来源官方限制 |
| HTTP 429 | 请求频率或额度受限 | 等待提示的重试时间，缩小任务并错开调度 |
| HTTP 5xx | 来源服务端暂时异常 | 稍后重试；部分来源失败不会影响同任务其他子步骤 |
| 部分成功 | 多步骤任务中只有部分步骤完成 | 打开运行详情，只重试失败步骤对应的来源条件 |
| 已有任务运行中 | 同一任务并发触发被锁保护 | 等待当前运行结束，不要重复点击 |
| Windows 触发器缺失 | 本地任务存在，但系统计划任务已被删除或未安装 | 刷新状态并重新执行“安装 Windows 触发器” |
| 免费模型不可用 | 本机网关未启动或所有免费渠道不可用 | 启动网关，刷新渠道状态；不会自动调用付费模型 |
| 数据库不可写 | 软件目录/数据库目录无写权限或文件被占用 | 把完整软件目录移到当前用户可写位置，关闭占用数据库的程序 |
| CSV 无法导出 | 目标文件正在被 Excel/WPS 占用或目录不可写 | 关闭占用文件，换到可写目录后重试 |

## 七、已知限制

- 软件是本地桌面应用，不提供多用户并发服务端和远程凭据管理。
- 打包目录必须可写；只读目录会安全失败，不会创建半成品数据库。
- Windows 自动运行依赖系统任务计划程序；只创建本地任务不能保证软件关闭后自动执行。
- ENTSO-E 当前统一保存 UTC 时间，但还没有按每个区域自动选择当地交易日。
- Elecheck Authorization 需要授权方提供，软件无法代替用户注册、登录或绕过权限。
- GridStatus 和部分 LLM 免费渠道存在第三方套餐、配额和限流，软件不能保证外部额度。
- 本机 LLM 网关默认只适用于同一台电脑的回环地址，不会自动暴露到公网。
- 大范围导出仍受本机磁盘空间和 CSV 工具能力影响；GUI 浏览采用分页/上限，不一次加载整表。
