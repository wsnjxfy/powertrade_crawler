# 定时任务精细检查与真实验收报告

验收日期：2026-08-07
验收范围：来源级增量计划、GUI、CLI、Agent、Windows 任务计划、真实网络采集、重复更新、打包运行。

## 最终能力

- `Elecheck`：所有或指定地区现货、近两月代理购电、增量机制电价。
- `ENTSO-E`：指定竞价区的日前价格、实际总负荷、按类型实际发电。
- `Elexon`：系统价格、初始需求实绩、风电预测、燃料类型发电、互联线潮流。
- `GridStatus`：数据集目录、CAISO 燃料结构、PJM 日前节点电价、NYISO 燃料结构更新。
- `广州电力交易中心`：公开信息列表和文章正文。

GUI 提供来源级快捷创建，默认时间为每天 09:00，并明确区分“本地启用”和
“安装 Windows 自动触发器”。高级任务入口继续保留单 Spider、指标重建和数据库维护。

## 关键修复

1. 新增 `source_update` 任务类型，一条任务可以顺序执行同一来源的多个安全子任务。
2. 每个子任务独立捕获失败；部分失败记为 `partial`，其余步骤继续，进程返回非零退出码。
3. Elecheck 新数据库首次只抓取昨天；后续每次回看一天并最多追赶 7 天，避免意外抓取多年历史。
4. GridStatus 每日计划排除带固定 2023 日期的 ERCOT 示例。
5. 来源级日期窗口在每次运行时重新计算，不会永久重复创建当天写死的日期。
6. 定时任务参数递归拒绝 API key、token、Authorization、password、secret 和 credential。
7. 同名任务返回可读错误，不再暴露数据库唯一约束异常。
8. Agent 可以识别“每天9点自动抓取elecheck来源新数据”，并在用户审批后创建来源级任务。
9. 新增 `schedule-create-source` CLI，并提供五个默认禁用来源模板。
10. GUI 保留操作结果状态，不再被紧随其后的“已刷新”覆盖。

## 使用建议

新用户优先在“API 配置向导”完成 Elecheck、ENTSO-E、GridStatus 凭据配置，再进入
“定时任务 / 数据维护 -> 快捷更新”。建议不同来源错开 5 至 10 分钟，减少同时联网和
SQLite 写入竞争。创建后应在任务列表确认“Windows 触发器 = 已安装”，并先执行一次
“立即运行”查看最近运行记录。
